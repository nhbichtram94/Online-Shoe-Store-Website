# Online Shoe Store Website

An e-commerce web application developed using **ASP.NET MVC** and **SQL Server**. The system enables customers to browse products, search for products, manage shopping carts, place orders, and allows administrators to manage products and customer orders.

---

## Overview

This project was developed as part of the **Web Programming** course at Ho Chi Minh City University of Industry and Trade (HUIT).

The objective is to build a simple and user-friendly online shopping platform while supporting essential store management functions.

---

## Features

### Customer

- Register and Login
- Browse Products
- Search Products
- View Product Details
- Manage Shopping Cart
- Place Orders
- View Order History

### Administrator

- Manage Product Categories
- Manage Products
- Manage Customer Orders

---

## Business Processes

The system supports the following business processes:

- Inventory Restocking
- User Registration
- Order Placement
