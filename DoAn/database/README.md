# Database

This folder contains the SQL Server database resources for the **Online Shoe Store Website**.

## Overview

The database is designed to support the core business operations of an online shoe store, including product management, customer accounts, shopping carts, and order processing.

## Main Modules

- User Management
- Product Categories
- Products
- Shopping Cart
- Orders
- Order Details

## Database Platform

- Microsoft SQL Server

## Purpose

The database provides persistent storage for the application and ensures data consistency through relational tables and constraints.
