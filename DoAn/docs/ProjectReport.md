# Project Report

## Project

**Online Shoe Store Website**

## Objective

Develop an e-commerce website that allows customers to browse products, place orders, and enables administrators to manage products and customer orders efficiently.

## Main Business Processes

- Inventory Restocking
- User Registration
- Order Placement

## Functional Modules

### Customer

- Register
- Login
- Browse Products
- Search Products
- View Product Details
- Shopping Cart
- Checkout
- Order History

### Administrator

- Product Management
- Category Management
- Order Management

## Technology Stack

- ASP.NET MVC
- C#
- Entity Framework
- SQL Server
- Bootstrap
- HTML/CSS
- JavaScript

## Deliverables

- Source Code
- SQL Database
- Project Documentation
